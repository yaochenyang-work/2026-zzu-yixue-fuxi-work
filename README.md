# 2026-zzu-yixue-fuxi-work
这是一款由deepseek生成的，用于医学生复习的一款app。基础功能包括：设置、做题、思维导图、题库。题库可以自行建立，也可在设置内导入，导入来源为系统储存。题型包括识图题、单选题、多选题、名词解释题、判断题、问答题以及病理分析题。“做题”区相较“题库”额外增加一项“错题”。思维导图可以自己构建，同样的也可以导入思维导图，不过需要由该软件导出的才可导入进去。附带寄生虫学题库，题库来源：识图题来自虚拟实验平台，单选多选来自雨课堂6次作业和白皮书，部分白皮书习题可能有误，故在“解析”一栏特别标注“白皮”，需要自行勘误。题库由人工导入
部分素材来源网络，数据正确与否需要自行判断。
